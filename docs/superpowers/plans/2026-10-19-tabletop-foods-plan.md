# 立体食物摆盘实施计划

已批准的设计：../specs/2026-10-19-tabletop-foods-design.md。

1. 创建独立的 26.2 Fabric / Java 25 工程，复用已有 Gradle wrapper 与缓存，注册摆放食物实体、同步数据和物品交互事件。
2. 实现服务端摆放权限、单份扣除、空手收回、击打回收、支撑丢失掉落与完整物品组件持久化；客户端实现固定姿态的物品实体渲染。
3. 制作覆盖全部原版食物和零食包三种食物的原生 JSON 模型，添加可重复运行的模型生成工具及覆盖与引用检查。
4. 进行构建检查，并在独立开发客户端验证生存数量、组件、支撑、食用、箱子交互、保存重载和模型外观；必要时修复后重测。
5. 打包 JAR、中文说明和试玩包；校验后安装到 PCL 的 26.2-Fabric 0.19.3 实例，提供实机预览与使用方法。

本地原有的冒险零食包未提交改动保持原状。制作阶段先完成本地交付；用户现已另行授权上传本模组源码并发布 GitHub 1.0.0，发布时仅提交本模组相关内容。

完成记录：43 个定制模型及其资源检查通过；66 项运行检查通过；实际鼠标右键摆放与收回数量正确；43 份展台食物在完整重启后保持 UUID 与物品身份。成品和试玩包已生成，并按 SHA-256 一致性检查后安装到目标 PCL 实例。
